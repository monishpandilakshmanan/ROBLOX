# GAMEHUB Login UI

A responsive, front-end-only gaming login page inspired by the layout and dark visual style of the supplied reference. It uses original GAMEHUB branding and a joystick SVG mark.

## Run locally
1. Extract the project folder.
2. Open `index.html` in a modern browser.

No build tools are required. HTML, CSS, and vanilla JavaScript are used.

## Included interactions
- Login and sign-up form mode switch
- Basic browser-side form validation
- Demo messages for password recovery, email one-time code, and quick sign-in
- Responsive layout for mobile and desktop

## Important security note
This is a UI prototype only. It intentionally does not send or store passwords and does not implement real authentication. For production, connect a trusted authentication provider or a secure backend, use HTTPS, validate on the server, rate-limit attempts, and implement recovery/OTP flows securely. Never store plaintext passwords.
